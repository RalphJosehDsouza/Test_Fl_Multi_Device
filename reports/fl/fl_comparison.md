## Objective 4: Data Privacy

Each client sends only **per-bin gradient, hessian, and count sums** -- never
raw transactions, model weights, or individual predictions. The server
combines these sums to pick splits and set leaf values.

- Total client -> server traffic: **3,636,792 floats (29.094 MB)**
- Aggregation invariant: max |pooled - sum| = 7.948983693495393e-10
- Federated vs pooled probability gap: 3.3306690738754696e-16

## Objective 5: Federated Aggregation

The model is trained by level-wise histogram GBDT. The aggregation is a
plain sum of per-bin statistics -- the same additive structure that Secure
Aggregation (Objective 6) would mask, once that work is done.

- Trees: 60
- Clients: 3
- Training time: 113.83s

## Interpretation

The federated model matches the centralised baseline to within 0.5%
ROC-AUC. The gap is attributable to the difference between level-wise
(federated) and leaf-wise (LightGBM) tree growth, not to data loss from
federation.
